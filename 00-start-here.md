# Start Here - SNS Skill Vault

This vault is for stable operating memory, not raw run clutter. Start here when
Obsidian feels noisy.

  operating memory for the skill.

  relationship map for Seedance, image anchors, camera transitions, and ChatCut.

## Authority Ladder

1. [[viral-social-remix/SKILL|SKILL.md]] decides route and execution order.
2. [[viral-social-remix/references/cooking-video-workflow|Production references]]
   define the current workflow contract.
3. [[docs/memory/viral-social-remix/index|Memory notes]] explain reusable
   lessons, costs, taste, and post-production habits.
4. [[docs/retrospectives/2026-07-23-chinese-remix-source-drift|Retrospectives]]
   explain why a guardrail exists.
5. `output/<run>/qa/run-notes.md` records one run; promote only reusable lessons.

If two notes disagree, trust the higher layer and update the lower memory note.

## Teaching Materials

`new_base/` is raw teaching/source material for future skill updates. Keep it
locally, read it when the user asks Codex to learn from a new document, and
distill reusable rules into the proper memory or reference note, such as
[[docs/memory/viral-social-remix/seedance-prompt-optimizer]]. It is filtered out
of Obsidian graph noise, but it is not trash.

## Do Not Read Everything

Read the route map first, then only the linked notes needed for the current
task. The goal is a connected vault, not a bigger pile of context.
