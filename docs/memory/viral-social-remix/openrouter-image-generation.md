# OpenRouter Image Generation Memory

## Default

Use the local runner for production carousel/storyboard generation:

```powershell
.\.venv\python.exe viral-social-remix\scripts\run_openrouter_carousel.py --run output/xxx --api-only --concurrency 2
```

Current default route:

- Endpoint: OpenRouter `/api/v1/images`
- Model: `openai/gpt-image-2`
- Quality: `medium`
- Concurrency: maximum 2 by default
- Output: `generated/page-XX.png`
- Raw sanitized response: `raw/page-XX-response.json`
- Cost summary: `qa/openrouter-cost.json`

## Why

The chat-completions image route previously returned square images for a
portrait Xiaohongshu request. For carousel production, prefer the dedicated
Images API unless the user explicitly asks for the legacy model route.

## API-Only Rule

When `--api-only` is enabled:

- Every missing page must be generated by API.
- A failed page stops the run.
- Do not create local fallback composites.
- Already-generated pages with the correct dimensions are skipped for resume.

## Cost Habit

Choose a model that matches quality needs and budget. It is fine to pick a
cheaper model when the task is layout-preserving and reference-heavy, but final
pages must still pass visual QA for text, products, and brand fidelity.

Record total cost in `qa/openrouter-cost.json`. Mention the cost to the user
after a successful run.
