# 视频剪辑主题库

主题不是“套一个风格”。低级模型必须同时改变开头承诺、镜头取舍、节奏、
文字密度、声音和结尾，才算真正应用主题。

## 选择方法

先问三件事：

1. 观众看完要得到什么：信息、食欲、信任、情绪、证明还是行动？
2. 素材最强的真实证据是什么？
3. 哪个主题能最早展示这个证据，又不需要编造缺失画面？

一个视频选一个主主题。辅助主题只能增强主主题，不能争夺控制权。

## 快速矩阵

以下镜头长度是短视频默认起点，不是硬规则。

| 主题 | 首屏承诺 | 常用镜头节奏 | 文字 | 声音 | 结尾 |
| --- | --- | --- | --- | --- | --- |
| 感官食欲 / ASMR | 先给最诱人的质感 | `0.5-1.5s`，动作点切 | 极少 | 真实 Foley 主导 | 咬下、拉丝、蒸汽或成品 hero |
| 懒人 / 省时 / 一锅出 | 少步骤也能完成 | 前快后稳 | 时间/步骤短标签 | 轻快 BGM + 关键烹饪声 | 一锅成品 + 实用 CTA |
| 教程 / How-to | 你能照做 | `1-2.5s`，步骤完整 | 步骤和关键量 | 清楚旁白或轻 BGM | 成品 + 保存/复做提示 |
| Talking Head 观点 | 先给最强观点 | 语义切，`2-6s` 内有变化 | 关键词，不抄满屏 | 对白绝对优先 | 结论或下一步 |
| 科普 / Explainer | 一个问题会被讲明白 | 问题—机制—例子 | 定义、数字、关系 | 旁白 + 克制提示音 | 一句总结 |
| UGC 商品安利 | 真实问题被解决 | `0.8-2s`，证明导向 | 痛点、卖点、CTA | 人声/自然口吻优先 | 使用结果 + 行动 |
| App / 网站 Promo | 一个动作完成一个结果 | UI 动作完整，减少装饰切 | 操作动词 | 轻科技感 BGM | 明确入口或下一步 |
| 测评 / 对比 | 哪个更好，为什么 | 成对镜头、同条件比较 | 维度和结论 | 一致音量，少情绪操纵 | 分人群推荐 |
| Before / After | 变化值得看 | 前后呼应，过程压缩 | Before/After 或一项指标 | 转折处声画同步 | After 多留一点时间 |
| 清单 / Starter Pack | 看完获得一套选择 | 项目化节拍 | 编号 + 名称 | 每项同一音型 | 总结选择逻辑 |
| 高级品牌 / Editorial | 质感和控制感 | `1.5-3s`，允许留白 | 少而准 | 空间感、细节声、克制音乐 | 品牌/商品 hero |
| 日常真实 / Vlog | 陪伴和可信 | 呼吸自然，不剪净所有停顿 | 时间/地点点到即止 | 环境声保留 | 小结果或自然离场 |
| 故事 / 转折 | 发生了什么 | 信息随冲突升级 | 时间、地点、转折词 | 音乐随情绪变化 | 回扣开头 |
| 悬念 / 揭秘 | 答案稍后出现 | 隐藏关键结果但持续给证据 | 问题式短句 | 递进，不滥用轰鸣 | 答案 + 回看价值 |
| 节日 / 季节 | 此时此刻为什么相关 | 氛围镜头可稍长 | 节点信息少量 | 对应环境感，不靠俗套音效 | 分享/团聚/限时行动 |
| 幕后 / Process | 真实是怎样做出来的 | 困难—过程—成果 | 工序/时间点 | 工具声和环境声 | 成果与团队/过程呼应 |

## 主题 1：感官食欲 / ASMR

适用：料理、饮料、开箱、质感商品。证据必须是可见或可听的触感。

Beat：

1. 最诱人的成品、汁水、蒸汽、脆响或倒入动作。
2. 两到四个关键制作动作，不交代所有行政步骤。
3. 热变化或质地变化。
4. 成品 hero、夹起、切开、入口或倒满。

ChatCut 执行：

- V1 保持紧密动作，优先在接触、倒入、切开、翻炒和抬起的动作点切。
- A3 放与画面同步的 sizzling、pour、chop、crunch 等 Foley；看不到动作就不加。
- A2 BGM 只负责速度和情绪，不能盖住食物声音。
- V3 最多放菜名、一个卖点或短步骤，不要做完整配方墙。

避免：过多转场、宽景空镜、假咀嚼声、全程大字遮住食物。

## 主题 2：懒人 / 省时 / 一锅出

适用：one-pan、15-minute、grocery shortcut、weeknight meal。

Beat：

1. 成品 + 真实约束：少锅、少步骤、快。
2. 材料或商品只出现解决问题所需的部分。
3. 过程按“放入—变化—完成”压缩。
4. 一锅/一盘结果证明承诺。

ChatCut 执行：

- 前 2 秒快，进入关键烹饪变化后稍放慢，让观众确认“真的做成了”。
- 重复切菜、搅拌和等待用一次代表动作即可。
- 标签用动作语言：`Add`、`Stir`、`Simmer`、`Serve`。
- 如果有商品，放在它真正解决麻烦的步骤，不要单独插广告。

避免：没有证据却写“5 分钟”；步骤剪得快到无法复做。

## 主题 3：教程 / How-to

适用：食谱、软件操作、手工、流程示范。

Beat：

1. 先展示完成结果。
2. 交代起点和必要条件。
3. 按因果顺序展示关键步骤。
4. 展示检查点：观众如何知道自己做对了。
5. 完成结果和下一步。

ChatCut 执行：

- 为每个步骤保留动作开始、关键接触和完成状态。
- 用 Motion Graphics 做统一步骤模板，每个实例只改编号和短文字。
- UI 教程不要在鼠标点击完成前切走；料理教程不要在质地变化前切走。
- 长解释可以用 Transcript 先删重复，再用 B-roll 遮盖合理跳切。

避免：只给漂亮蒙太奇，没有步骤；字幕与动作错位。

## 主题 4：Talking Head 专业观点

适用：访谈、知识分享、创始人发言、用户证言。

Beat：

1. 最强观点或反常识句，不先放寒暄。
2. 一句上下文。
3. 两到三个理由或例子。
4. 结论、建议或 CTA。

ChatCut 执行：

- 在 Transcript 中按语义删除口头语和重复，不能删到主谓宾断裂。
- 保留必要呼吸，不要让每句话都像机器连读。
- 每 `4-8s` 需要一种有意义的视觉变化：B-roll、构图变化、关键词或例子。
- 字幕服务理解，关键词强调不超过一小部分。
- A1 对白优先，A2 自动让位；房间环境声不要在每个跳切突然断掉。

避免：用 B-roll 遮住重要表情；删除限定词导致观点变得绝对。

## 主题 5：科普 / Explainer

适用：产品原理、政策解释、知识点、机制说明。

Beat：

1. 一个清楚问题。
2. 一句直接答案。
3. 机制拆成最多三个部分。
4. 真实例子或对照。
5. 结论和应用。

ChatCut 执行：

- Motion Graphics 只画关系：步骤、层级、因果、前后对比。
- 每个画面只解释一个概念；旁白变概念时视觉也变。
- 数字、定义和引用必须来自输入事实。
- 可以另建一条短 timeline 做 `30s` 版，保留同一结论而不是简单倍速。

避免：用花哨动效替代解释；同时出现太多标签。

## 主题 6：UGC 商品安利

适用：真实体验、商品演示、URL to Ad Video、社媒广告。

Beat：

1. 具体痛点或欲望。
2. 商品进入真实使用情境。
3. 一个核心机制/卖点。
4. 可见证明。
5. 适用人群、限制和 CTA。

ChatCut 执行：

- 优先保留手持、实际使用和自然反应，不要剪成纯棚拍。
- 商品名称第一次出现要清楚，但不持续霸屏。
- 卖点文字必须能在画面、台词或用户资料中验证。
- CTA 放在 Proof 后；没有 Proof 时先补证据，不用动效硬推购买。

避免：虚构折扣、库存、功效、五星评价；logo 先于价值。

## 主题 7：App / 网站 Promo

适用：App Promo、功能演示、网页产品介绍。

Beat：

1. 用户问题。
2. 进入产品的最短路径。
3. 一次完整关键操作。
4. 明确结果。
5. 下一步。

ChatCut 执行：

- 点击前给观众定位，点击后保留结果加载完成。
- 画面区域引用要精确，放大只服务于目标控件。
- UI 变化是主要运动，转场不要抢注意力。
- 标签使用动词：`Search`、`Compare`、`Save`、`Order`。

避免：光标瞬移、放大后看不到上下文、用假界面补不存在的功能。

## 主题 8：测评 / 对比

适用：商品比较、方案选择、口味/价格/功能评估。

Beat：

1. 对比问题和对象。
2. 公平条件。
3. 逐项展示同一维度。
4. 解释差异对谁重要。
5. 分场景结论。

ChatCut 执行：

- 同一维度使用相近构图、时长和音量，避免剪辑偏袒。
- 用可复用 Motion Graphic 固定维度名称和 A/B 标识。
- 如果没有足够素材支持某维度，删掉该维度。
- 结论允许“不同人选不同”，不要强行制造赢家。

避免：A 用最好镜头、B 用最差镜头；把主观口味写成客观事实。

## 主题 9：Before / After

适用：改造、整理、修复、烹饪变化、数据变化。

Beat：

1. Before 的清楚状态。
2. 最少但关键的过程。
3. 转折动作。
4. 与开头构图呼应的 After。
5. 变化意义。

ChatCut 执行：

- 尽量匹配 Before/After 的机位、尺寸和时长。
- 可以在转折点使用一次明确声画强调；不要每一步都轰鸣。
- After 比 Before 多留一点时间，让观众完成比较。
- 没有真实 Before 或 After 时，不使用这个主题。

避免：前后光线和角度差异导致虚假夸大；没有过程证据。

## 主题 10：清单 / Starter Pack

适用：购物清单、调味料入门、Top items、组合建议。

Beat：

1. 清单解决什么问题。
2. 每项以相同模板出现：名称—用途—区别。
3. 最后给选择逻辑，不只重复列表。

ChatCut 执行：

- 每项采用一致的进入、标签位置和时长范围，形成可预测节奏。
- 用 V3 Motion Graphic 统一编号和名称。
- 重要项可稍长，不能只按资产数量平均分配。
- 最后一屏按需求分组：新手、快手、重口或预算，而不是“全部都买”。

避免：十几项飞快闪过；编号和画面对象不一致。

## 主题 11：高级品牌 / Editorial

适用：品牌片、新品 hero、质感商品、餐饮形象。

Beat：

1. 材质或动作细节，不急着解释。
2. 使用场景。
3. 设计/工艺证据。
4. 商品与结果的控制性 hero。

ChatCut 执行：

- 镜头可更长，让构图、材质、光线和声音承担叙事。
- 转场以形状、动作、方向或声音匹配为主。
- 文字少而准确，排版留白。
- 音乐和环境声要有空间，不用持续堆叠 riser 和 hit。

避免：把“慢”误当高级；没有证据只拍 logo；所有镜头都加速度变化。

## 主题 12：日常真实 / Vlog

适用：幕后、一天、探店、家庭料理、真实体验。

Beat：

1. 一个正在发生的小问题或期待。
2. 行动过程。
3. 不完美但真实的细节。
4. 小结果和感受。

ChatCut 执行：

- 保留少量环境声、犹豫和自然动作，建立可信度。
- 删除无信息等待，但不要把所有呼吸剪掉。
- 时间/地点标签只在真正帮助理解时出现。
- BGM 维持陪伴感，不把普通日常剪成预告片。

避免：每个动作都 speed ramp；过度磨皮和假反应。

## 主题 13：故事 / 转折

适用：案例、失败复盘、顾客故事、创业经历。

Beat：

1. 结果或冲突钩子。
2. 当时的目标。
3. 障碍升级。
4. 决定或发现。
5. 结果和新理解。

ChatCut 执行：

- 用 Transcript 保护因果关系；不要为了短而删掉关键前提。
- B-roll 显示证据和环境，不只是装饰。
- 音乐在转折处改变能量，但不要提前泄露结果。
- 结尾回扣开头的问题或画面。

避免：只有情绪没有事实；把多个事件剪成虚假因果。

## 主题 14：悬念 / 揭秘

适用：测试、答案型知识、幕后揭秘、结果未知的过程。

Beat：

1. 提出具体问题。
2. 连续给有价值的部分证据。
3. 排除错误猜测。
4. 展示答案。
5. 说明答案为什么重要。

ChatCut 执行：

- 不在首屏或字幕里意外泄露答案。
- 每个延迟都必须增加信息，不能只拖时长。
- 答案出现时用清楚画面和干净声音，不必堆叠多个效果。

避免：标题党；答案弱到不配前面的等待。

## 主题 15：节日 / 季节

适用：春节、圣诞、冬季饮品、夏季烧烤、开学、节庆购物。

Beat：

1. 当下场景或季节需求。
2. 与主题真正相关的产品/行为。
3. 准备或分享过程。
4. 人、食物或场景的情绪结果。
5. 有时效的下一步。

ChatCut 执行：

- 先使用素材中真实存在的季节证据：天气、服装、食物、装饰、活动。
- 色彩、音乐和 Motion Graphics 只做统一，不凭空制造活动事实。
- 限时、价格和日期必须由用户提供并复核。

避免：只加雪花贴纸就叫冬季；文化符号混用；虚构促销。

## 主题 16：幕后 / Process

适用：制作过程、仓库、厨房备货、拍摄现场、产品研发。

Beat：

1. 最终成果或“你没看到的部分”。
2. 原材料/起点。
3. 两到三个关键工序。
4. 难点或质量检查。
5. 成果回归。

ChatCut 执行：

- 保留工具、机器、包装、脚步和空间声，增加真实感。
- 工序标签应是具体动词或质量标准。
- 使用匹配动作把不同阶段连起来。
- 品牌露出来自真实环境、制服、包装或标牌，不做漂浮 logo。

避免：把流水线剪得过快而看不懂；用无关 stock B-roll 冒充真实过程。

## 主题冲突处理

常见冲突：

- `高级品牌` vs `懒人快手`：前者靠控制和留白，后者靠效率。只能选一个为主。
- `ASMR` vs `Talking Head`：一个以 Foley 为主，一个以对白为主。分段或选主次。
- `教程` vs `悬念`：教程要求尽快说清，悬念要求延迟答案。最多在开头做一个短问题，
  不要延迟关键步骤。
- `Vlog 真实` vs `UGC 广告`：前者保留自然不完美，后者需要明确证明和 CTA。
  可以保留真实质感，但不能隐藏商业目的。

冲突时优先顺序：

1. 事实正确；
2. 用户目标；
3. 观众理解；
4. 主主题一致；
5. 装饰性审美。
